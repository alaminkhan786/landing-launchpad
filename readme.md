# 🌐 WEBFLOW - Dark UI Landing Page Template

A modern, responsive, and visually appealing **dark UI landing page template** built using HTML5 and CSS3. Inspired by Webflow-style agency websites, this project showcases a clean layout, smooth design elements, and engaging components like testimonials, user stats, and a contact form.

---

## ✨ Features

- ✅ Clean and minimal **dark-themed** design  
- ✅ Google Fonts integration (Raleway & Inter)  
- ✅ Fully structured layout: `Header`, `Hero`, `Features`, `Reviews`, `Contact`, and `Footer`  
- ✅ Interactive buttons with hover transitions  
- ✅ Organized and semantic HTML  
- ✅ Modular and reusable CSS styles  
- ✅ Review/testimonial section with avatars and star ratings  
- ✅ Modern responsive form design  

---

## 🚀 Use Cases

- Webflow agency landing pages  
- UI/UX design portfolios  
- SaaS or startup product pages  
- HTML/CSS learning or practice project
